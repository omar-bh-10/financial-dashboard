# Banking Transactions Dashboard

A web application built with Flask that allows users to upload a bank transactions Excel file and automatically generate financial insights and visual reports.

## Features

- Upload Excel files (.xlsx)
- Analyze banking transactions
- Calculate key financial indicators (KPIs)
- Generate charts automatically
- Display revenues and expenses
- Current balance calculation
- Identify highest revenue and expense transactions

## Technologies Used

- Python
- Flask
- Pandas
- Matplotlib
- OpenPyXL
- HTML/CSS
